# Deskripsi
Pada update ini, saya menambahkan local storage untuk menyimpan tema yan terakhir digunakan dan Indexeddb untuk menyimpan todo list. Hal ini ditambahkan agar data todo tidak hilang saat web di refresh tapi akan hilang ketika di close. Selain itu saya menambahkan fitur kamer untuk menambahkan foto juga menambahkan service worker untuk memberikan notifikasi todo yang akan dilakukan.
